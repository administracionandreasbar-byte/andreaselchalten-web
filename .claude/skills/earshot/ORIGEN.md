# Origen de esta skill

Copia sin cambios de `skills/earshot/SKILL.md` de https://github.com/Leonxlnx/earshot (commit `7a7f7c5`, versión 1.0.0, 20/11/2026). Licencia MIT.

Esta carpeta trae solo las instrucciones. La herramienta es un paquete de Python que se instala aparte, desde GitHub
(el nombre `earshot` en PyPI es de otro proyecto):

    pip install "earshot @ git+https://github.com/Leonxlnx/earshot"

Del mismo repositorio quedó afuera la skill `real-sound` (una cadena de varios agentes para bandas sonoras completas
de películas hechas con código): es mucho más de lo que necesitan los reels de Andreas.
Cómo se usa en Andreas: ver la skill `sonido-reels`.
